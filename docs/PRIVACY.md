# 数据和网络边界

首次安装的三个服务器配置、Token、访问密钥和更新源均为空，不包含开发者或用户的配置。应用功能不依赖 Codex Skill。

服务器配置保存在本机 Keychain；独立服务标识为 `com.doc.frpmodelchat.configuration`。不读取或迁移原 FrpClient 的 Keychain 服务。聊天历史保存在应用私有目录并排除设备备份；不同配置和连接身份的历史分开保存。签名身份或 Bundle ID 改变可能影响凭据访问。

消息通过本机回环端点和当前 STCP 隧道发送到用户配置的远端模型服务。项目不提供模型、服务器或遥测服务，不记录提示词及回复诊断日志。远端模型、发布端和中继服务器由用户管理；这些服务自己的记录和保留规则不由本应用控制。

聊天请求不跟随 HTTP 重定向，不使用 Cookie、系统代理或持久缓存。手动更新检查仅访问用户显式设置的 HTTPS 清单地址；默认不配置地址，发布没有部署在线更新清单。

后台连接辅助可选择授权定位，拒绝后仍可在前台使用。授权和锁屏卡片不能保证 FRPC 永久在后台运行。实时活动可能在锁屏上展示配置编号、连接阶段和时长；系统挂起或回收后，画面可能滞后，不能作为实时在线证明。

本仓库和 Release 不包含真实 Keychain、服务器配置、聊天、设备状态、开发过程日志或原始验收截图。反馈问题时，请自行脱敏这些内容。
