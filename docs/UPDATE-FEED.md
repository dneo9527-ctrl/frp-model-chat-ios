# 版本清单

1.4.0 新增“设置 → 检查更新”。本独立项目目前没有部署公开更新源，安装包默认留空；空源检查不会联网，也不会显示“已是最新”。在“更新源设置”填写发布者提供的 HTTPS JSON 地址后，可手动检查。

清单示例（域名仅为占位，不是可用的发布地址）：

```json
{
  "bundleIdentifier": "com.doc.frpmodelchat",
  "version": "1.4.1",
  "build": 8,
  "notes": "本次更新说明。",
  "releasePage": "https://example.invalid/releases/1.4.1#ios"
}
```

要求：清单及发布页均使用 HTTPS，无 URL 账号密码。清单地址不接受 fragment，发布页可以有锚点。清单须直接返回 HTTP200，不自动跟随重定向；最多64KiB，说明最多16KiB。版本为三段非负整数的稳定版号，build为1至999999999的整数。先按版本数值比较，再比较同版本的 build。bundleIdentifier必须与本独立应用一致，避免误接旧项目清单。

检查请求使用临时会话，不附带 frp 配置或聊天记录，不使用 Cookie/凭据存储；请求超时5秒、总资源超时8秒。更改更新源会取消旧请求并清除旧结果。只有发现更高版本才提供发布页链接，点击后交给浏览器；不下载IPA、不自动安装、不替换签名。安装新版仍需原安装渠道支持；保留数据还取决于使用相同的应用标识和兼容签名，不保证跨签名迁移。

发布更新源、上传IPA或接入公共仓库属于外部发布，尚未执行。后续有正式发布渠道时，填入真实地址并单独验收即可，无需改动聊天隧道。
