# Frp 模型对话 1.4.2 · Build9

按用户反馈，将深色模式改为黑色与中性灰。

- 页面底色为纯黑；卡片、输入框为深灰，用户气泡使用稍亮的灰色区分。
- 深色模式的常规操作、模型菜单与应用内标识不再使用蓝绿色。连接成功、警告和错误保留语义颜色。
- 发送、保存并连接等浅色填充按钮使用黑色图标或文字；左滑重命名使用深灰底，避免白字叠白底。
- 浅色主题、桌面图标、连接方式和聊天功能保留。

版本为1.4.2（Build9），独立标识继续为 `com.doc.frpmodelchat`。
